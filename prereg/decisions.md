# Pre-registered implementation decisions

Locked before any P1/P2/P3 training run. Changing any entry requires a dated note here.

## Loss normalisation (single-step update, B0c)

- Date: 2026-11-12
- Loss = sum over response tokens of (-A * ratio * loss_mask * loss_weight) / (N_orig_global * L).
- N_orig_global: number of original trajectories in the step, all-reduced over ranks (B=128, G=5 -> 640).
  Sibling trajectories (P3) do not count toward N_orig; they enter with loss_weight = 1/M.
- L = 500 = data.max_response_length, a fixed constant (config: actor.plan_loss_len).
  Chosen so the gradient scale stays close to the original token-mean loss and lr=1e-6 / grad_clip=1.0
  can be reused without retuning. It is a constant, so it does not affect unbiasedness.
- Local loss is multiplied by world_size because FSDP averages gradients across ranks (to be confirmed by B0b / R004).
- KL loss applies to original trajectories only; entropy_coeff = 0.
- Enabled with actor.plan_single_step=True; requires ppo_epochs=1, temperature=1 (asserted).

## Lexical phi (Block 3 diagnostic, R006)

- Date: 2026-11-12. Code: search_r1/plan/lexical_phi.py, test: scripts/plan/r006_lexical_test.py.
- Retrieval-action phi = 1 if any golden alias appears in the docs of the post-retrieval state S, else 0.
  Answer-action phi stays EM.
- Docs are cumulative (all <information> blocks in S), matching the reader score Phi(S) = f(docs(S)).
- "Substring match" in the plan is made precise as whole-token matching after qa_em.normalize_answer:
  plain substring would let short answers ("1", "he") match inside longer tokens ("1990", "the").
- Aliases that normalise to "" are dropped; a question with no usable alias gets phi = 0.

## Rollout trace, turns and fork (checklist item 2)

- Date: 2026-11-12. Code: search_r1/llm_agent/generation.py, test: scripts/plan/p3_fork_test.py.
- max_turns = 3 retrieval rounds, so up to K = 4 decision turns (turn 4 is the forced final turn; a
  search issued there is not executed, as in Search-R1). k* ~ Uniform{1..4}, drawn per trajectory
  before the rollout; trajectories that stop before k* are not forked (P2-sel / P3 get no adjustment).
- Each response token carries its decision-turn id; observation, prompt and padding tokens carry 0.
- Siblings are drawn in the same vLLM call and from the same prefix as the true action at k*; their
  searches go in the same retrieval batch; they are never continued.

## Per-action phi

- Executed search: Phi(S_{k-1} + docs) (reader). Answer: EM against the gold aliases (also under negctrl).
  Invalid action, or a search on the final turn (not executed): phi = Phi(S_{k-1}).
- P1 turn reward Phi(S_k) - Phi(S_{k-1}) is defined on executed-search turns only (one potential
  evaluation per retrieval round); z_turn pools those turn rewards over the GRPO group with the
  same convention as GRPO z (unbiased std, eps 1e-6, singleton -> mean 0, std 1).
- P3: C_0 = mean of the M sibling phis; C_j = leave-one-out mean over the other M candidates.
  Exact zero expectation of the correction is checked in scripts/plan/item34_advantages_test.py.

## Reader prompt (checklist item 6)

- Reader Qwen2.5-7B-Instruct, bf16, frozen, its chat template, user message =
  "Answer the question based on the documents. Reply with only the answer.\n\n" + docs block + "Question: q".
- Docs block: "Document n: (Title: t) text\n" per doc, in retrieval order over all executed searches
  of S; identical passages kept once (first occurrence); each doc cut to 256 reader tokens; earliest
  docs dropped until the block is <= 2048 tokens. Built at token level (no re-tokenisation).
- Phi = exp(mean token log-prob of the alias right after the generation prompt), max over the
  distinct non-empty aliases. No docs -> empty block (closed-book).
- Test: scripts/plan/item6_reader_test.py.

## Negative control

- Answer class on the first alias: yes/no, else date (year, d/m/y, month name with digit), else
  number (digits, number words), else entity.
- Map over all training-side qids (train_pool + pilot_calib + pilot_eval, key "data_source/id"):
  within each class, the sorted qids in a seed-0 random order, each mapped to the next one
  (cyclic, so no question keeps its own answer). Answer phi keeps the true EM.
- File data/prereg/negctrl_map.json, regenerated by scripts/plan/make_negctrl_map.py.
  n = 168,615, sha256(sorted items) = df8a0d74f6e0373e0afe515b828dabd498b15ec37bc03f4550d0521e2cd44361,
  class counts: date 24,139, entity 132,539, number 6,492, yesno 5,445; fixed points 0.
